# حزمة فيديو خط تغذية الدواجن والأسلوب المحدّث

تضم النسخة النهائية للفيديو والتعليق والنص وخطة المشاهد، وتغييرات المحرك ذات الصلة، وإعدادات الأسلوب المثبّتة للمقاطع المقبلة.

## التعديلات المثبّتة

- الكابشن يطابق المنطوق فقط، ولا يخلط العربية بالإنجليزية أو يضيف عناوين.
- قطاع الأرض متصل بعرض الكادر وعمقه الافتراضي 10 وحدات، مع سبع طبقات متمايزة ومتساوية.
- مباني الدواجن تستخدم ألواحًا خشبية/طوبًا واقعيًا؛ الفتحات منخفضة بما يكفي لإظهار الآلية.
- تمت مراجعة معاينة الفيديو النهائي ومدة الصوت ودقة 1080×1920/30fps.

## إعادة استخدام ملفات المشروع

هذه الحزمة تسليم للمشهد والتغييرات وليست نسخة مستقلة بكل مكتبات وأصول Diorama Studio. لتشغيلها، انسخ محتويات مجلد `project/` إلى جذر نسخة المحرك الموجودة لديك في `/workspace/diorama-studio`، واستبدل الملفات ذات المسارات نفسها. وتُنسخ ملفات `style/` إلى `/workspace/video-factory`. الأصول العامة وNode dependencies تبقى من المشروع المثبت.

الفيديو النهائي موجود في `video/final.mp4`، ولوحة المراجعة في `video/review-sheet.jpg`.
