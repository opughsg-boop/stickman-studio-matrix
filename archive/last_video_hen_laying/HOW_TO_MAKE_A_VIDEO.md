# دليل عمل فيديو زي آخر فيديو (Diorama Studio)

آخر فيديو: **إزاي الفلاح بيعرف الدجاجة بتبيض، من غير ما يشوفها؟** (54.7 ثانية، سكور 58/100).
الملف ده يكفي لأي محادثة جديدة تعمل فيديو بنفس الطريقة والأدوات.

## 1. قبل ما تبدأ
- اقرأ `CLAUDE.md` كامل (قواعد الأسلوب والتحسين والتلامس).
- اقرأ `STYLE_GUIDE.md` قسم 2b (الواقعية المقفولة).
- اقرأ `memory/visual_lessons.md` وقارن الخطة بيه (خصوصًا: الإيد، الـ dead beats، الكاميرا).
- اقرأ `memory/lessons.json` وتأكد إنه JSON صالح: `python3 -m json.tool memory/lessons.json`.
- اقرأ `ZID.md` و`DIORAMA_SKILL.md` للمرجعية.

## 2. الملفات اللي محتاجها من الفيديو السابق
| الملف | الدور |
|---|---|
| `script.txt` | السكريبت، سطر لكل جملة منطوقة |
| `voice.wav` | صوت المستخدم (54.7 ثانية) |
| `hen_laying.mjs` | خطة المشاهد (بنفس بنية `plans/wood_bed.mjs`) |
| `transcript.json` | التوقيتات الناتجة من الصوت (بتتولد تلقائيًا) |
| `plan.json` | الخطة الناتجة بعد التشغيل |
| `final.mp4` | الفيديو النهائي |
| `critic.log` | تقرير التقييم |
| `sheet_final.jpg` | شيت الفيديو النهائي |

## 3. خط الإنتاج خطوة بخطوة
1. **السكريبت:** احفظه في `runs/<name>/script.txt`، سطر لكل جملة منطوقة. ما تغيّرش نص المستخدم.
2. **الصوت:** انسخه لـ `runs/<name>/voice.wav`. اتأكد من المدة: `ffprobe -v error -show_entries format=duration -of csv=p=0 runs/<name>/voice.wav`.
3. **الخطة:** اكتب `plans/<name>.mjs`. الهيكل:
   - `at(i)` و`word(i, regex)` لتوقيت كل مشهد من الـ transcript.
   - `env`: سماء واقعية، تربة `brown_mud_leaves_01`، أفق `nile` للريف.
   - `style`: `camEase: .6`، `captionY: .78`، `exposure: 1.1`.
   - بيانات كل مشهد: `add`, `remove`, `modes`, `camera`.
   - كل مشهد يتعمل بزاوية كاميرا جديدة أو حالة جديدة. ممنوع المشاهد المكررة.
4. **فحص الصياغة:** `node --check plans/<name>.mjs`.
5. **المعاينة (مرة واحدة):**
   ```bash
   node run.mjs --audio runs/<name>/voice.wav --script runs/<name>/script.txt --plan plans/<name>.mjs --lang ar --out runs/<name> --preview-only
   ```
   افتح `runs/<name>/sheet_preview.jpg` **مرة واحدة** بس، واعمل التعديلات.
6. **الرندر الكامل** (من 25 لـ 40 دقيقة، شغّله في الخلفية):
   ```bash
   node run.mjs --audio runs/<name>/voice.wav --script runs/<name>/script.txt --plan plans/<name>.mjs --lang ar --out runs/<name>
   ```
   - لو وقف عند 90%: أعد نفس الأمر، والـ chunks بتتعاد استخدامها.
   - لو وقف عند التقييم (`critic.py`): اتأكد من صلاحية كل ملفات JSON في `memory/` و`runs/<name>/`.
7. **التقييم:** لو التقييم اتعمل بعد الرندر، شوف السكور في `runs/<name>/run.log` أو شغّل:
   ```bash
   python3 pipeline/critic.py runs/<name>
   ```
8. **التسليم:** ابعت `runs/<name>/final.mp4` للمستخدم، وقول السكور في 3 أو 4 سطور وإيه اللي اتحسن.
9. **الـ commit والـ push:** اعمل commit للخطة والكود والـ memory، وبعدين `git pull --rebase origin diorama-studio` ثم `git push origin diorama-studio`.

## 4. القواعد اللي لازم تتطبق
- **التحسين 1x في ثلاث حاجات كل فيديو:** الحركة، والرسوميات، والواقعية. اكتب إيه اللي اتحسن.
- **التلامس:** الإيد والرجل لازم تلمس اللي بتمسكه أو تقف عليه، بفرق أقصاه 0.2 إلى 0.4 متر.
- **ممنوع كلام على الشاشة** غير الكابشن (جملتين كحد أقصى لكل سطر منطوق).
- **ستيكرز:** ويحصل أحيانًا تبقى مكررة مع ✓ و✗ اللي المحرك بيضيفها. ما تحطش ستيكر على مشهد فيه ✓/✗.
- **الصوت الخلفي أوطى من الصوت الرئيسي:** SFX وزنه 0.5، وبيات النحل `.035/.07`. ما ترفعش من غير طلب.
- **فيديو واحد لكل محادثة.**

## 5. مشاكل اتعرفت عليها ولازم تتجنبها
- **الإيد بتبان كلعبة** (أصابع ناعمة بدون مفاصل وأظافر). الحل: تفاصيل المفاصل والأظافر وتجاعيد الجلد، وفحص التلامس بالإحداثيات قبل الرندر.
- **مشاهد مكررة (dead beats):** الشيت بيوضح ده. الحل: مشهد جديد في كل مرة أو ادمج.
- **ملف JSON متكسر** من دمج Git: بيوقّف التقييم. الحل: `python3 -m json.tool` على ملفات `memory/*.json` بعد أي دمج.
- **الرندر بيقف عند 90%:** أعد التشغيل، والـ chunks بتتعاد.
- **تعارض Git في `renderer/scene.js`:** لما جلسات مختلفة تضيف أصول، الحل الاحتفاظ بالجانبين وإزالة علامات التعارض، وبعدين `node --check renderer/scene.js`.
